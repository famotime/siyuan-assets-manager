# 📦 资源管家 — 思源笔记资源文件管理插件

> 一站式管理思源笔记中的所有资源文件：看得清、找得到、编得了、理得净。支持**基于思源块属性的图片矢量二次编辑**与**原始底图隔离保护**。

---

## 你遇到过这些问题吗？

- 📸 笔记里插了上千张图片，哪些还在用、哪些已经没人引用了？
- 🗂️ 想给资源文件改个有意义的名字，却担心文档里的链接全部失效？
- ✏️ **标注过的图片想微调一个箭头或文字，却发现已经变成死像素无法修改？**
- 🧹 `assets` 文件夹越来越大，不知道哪些文件可以安全清理？

**资源管家** 就是为了解决这些问题而生的。

---

## ✨ 核心功能

### 📊 资源总览与统计

打开资源管家，即可看到思源笔记中 **所有资源文件** 的完整清单：

- **文件名、后缀名、文件大小** — 一目了然
- **引用数** — 每个资源被多少篇文档引用，清晰可见
- **图片缩略图** — 图片类资源直接展示缩略图预览，鼠标悬停可查看大图
- **二次编辑状态标记** — 带有历史矢量图层的图片显示蓝色的 `[可二次编辑]` 徽标
- **虚拟滚动列表** — 即使有几千个资源文件，依然流畅滚动不卡顿

### 🔍 搜索与筛选

快速定位你关心的资源：

- **关键字搜索** — 按文件名实时搜索
- **按类型筛选** — 全部 / 只看图片 / **只看可二次编辑资源** / 只看未引用的孤儿资源 / 只看大文件（>1MB）
- **多维度排序** — 按文件名、后缀名、文件大小、引用数排序（升序/降序）

### ✏️ 强大的图片编辑与【可二次编辑】（核心特色）

在思源内部直接编辑图片，无需切换到外部工具：

- **基础编辑** — 自由裁剪/比例裁剪、自由画笔涂鸦、矩形/圆形/多边形、文本标注、滤镜与马赛克
- **📍 序号标注** — 点击图片即可依次添加带编号的标注（①②③...），序号与底色形状自动联动
- **🔄 矢量图层二次编辑（Secondary Editing）**：
  - **历史图层可修改**：添加的箭头、文字、矩形等元素以矢量结构持久保存在图像块属性（`custom-asset-reedit`）中，再次打开时所有图层均可自由移动、拉伸、修改文本或删除！
  - **底图隔离保护**：干净未修改的原始底图隔离保存在插件专属目录（`storage/petal/siyuan-assets-manager/originals/`），彻底规避思源原生清理资源的误删风险，二次编辑时底图无任何残留重影。
  - **自适应高效压缩**：矢量数据自动采用 `lz-string` 编码压缩，体积极致小巧，保障数据库高性能。
  - **快捷操作**：支持一键**“重置为原始底图”**以及**“合并固化图层”**（降级为普通位图）。

### ✏️ 资源重命名

给资源文件一个有意义的名字：

- 在资源管家中选择任意资源，点击"重命名"
- 输入新文件名，确认后：
  - ✅ 物理文件自动重命名
  - ✅ **所有引用该资源的文档自动更新链接**，不会出现引用失效
- 智能后缀处理：忘记输入后缀名会自动补齐，修改后缀名会弹出确认
- 文件名合法性校验：自动拒绝包含非法字符（`\ / : * ? " < > |`）的名称

### 📄 查看引用文档

想知道某个资源被哪些文档使用了？

- 点击资源对应的 **"打开"** 按钮
- 自动在后台打开 **所有引用了该资源的文档**，并定位高亮到引用位置
- 一键跳转，快速追溯资源的使用上下文

### 🗑️ 删除资源

删除不再需要的资源：

- 点击"删除"后，物理文件被移除
- 文档中所有引用该资源的内容块也会被自动清理
- 如果清理后内容块变为空白，该块会被自动删除，保持文档整洁

### 🧹 资源与底图双重清理

- **清理孤儿资源**：一键识别并清理 `assets/` 中所有未被任何文档引用的资源文件。
- **清理孤立原始底图**：一键扫描并清理已被删除文档块遗留的二次编辑无主原始底图，彻底释放磁盘空间。

### 🖱️ 文档右键菜单无缝集成

无需打开资源管家面板，在文档中直接操作：

- 在文档中的图片上 **右键**，弹出 **"资源管家"** 子菜单
- **编辑标注** — 自动感知是否含有二次编辑图层，显示为 `编辑标注（已含历史标注）`，点击即刻还原矢量图层
- **重命名** — 直接重命名该图片资源，全库引用自动同步更新

## 🚀 如何使用

### 安装

1. 在思源笔记中打开 **集市** → **插件**
2. 搜索 **"资源管家"**（或 "Assets Manager"）
3. 点击安装并启用

### 打开资源管家

安装并启用后，思源笔记顶栏会出现 📦 **资源管家图标**，点击即可打开管理面板。

---

## ⚠️ 注意事项

- **清理操作不可撤销** — "清理"和"删除"功能会直接移除物理文件，操作前请确认资源确实不再需要
- **桌面端体验最佳** — 在 Electron 桌面端直接利用原生文件系统直写，大图秒存秒开；浏览器端通过 HTTP API 传输
- **首次加载** — 若资源文件数量极多（数千个），首次打开扫描可能需要几秒钟，后续操作均在内存缓存中极速完成
