# 📦 资源管家 — 思源笔记资源文件管理插件

> 一站式管理思源笔记中的所有资源文件：看得清、找得到、编得了、理得净。

---

## 你遇到过这些问题吗？

- 📸 笔记里插了上千张图片，哪些还在用、哪些已经没人引用了？
- 🗂️ 想给资源文件改个有意义的名字，却担心文档里的链接全部失效？
- ✏️ 截图需要加个标注，还得打开外部工具编辑、导出、再替换？
- 🧹 `assets` 文件夹越来越大，不知道哪些文件可以安全清理？

**资源管家** 就是为了解决这些问题而生的。

---

## ✨ 核心功能

### 📊 资源总览与统计

打开资源管家，即可看到思源笔记中 **所有资源文件** 的完整清单：

- **文件名、后缀名、文件大小** — 一目了然
- **引用数** — 每个资源被多少篇文档引用，清晰可见
- **图片缩略图** — 图片类资源直接展示缩略图预览，鼠标悬停可查看大图
- **虚拟滚动列表** — 即使有几千个资源文件，依然流畅滚动不卡顿

### 🔍 搜索与筛选

快速定位你关心的资源：

- **关键字搜索** — 按文件名实时搜索
- **按类型筛选** — 只看图片 / 只看未引用的孤儿资源 / 只看大文件（>1MB）
- **多维度排序** — 按文件名、后缀名、文件大小、引用数排序（升序/降序）

### ✏️ 图片编辑

在思源内部直接编辑图片，无需切换到外部工具：

- **裁剪** — 自由裁剪或按比例裁剪
- **画笔** — 自由涂鸦、标记重点
- **形状** — 添加矩形、圆形、三角形等几何图形
- **图标** — 插入预置图标
- **文字** — 在图片上添加文字说明
- **滤镜** — 调整亮度、对比度、模糊等效果
- **📍 序号标注（特色功能）** — 点击图片即可依次添加带编号的标注（①②③...），支持自定义：
  - 标注形状：圆形 / 方形 / 三角形
  - 背景色与文字颜色
  - 文字大小
  - 起始序号

编辑完成后保存，**所有引用该图片的文档会自动更新为新图片**，无需手动替换。

### ✏️ 资源重命名

给资源文件一个有意义的名字：

- 在资源管家中选择任意资源，点击"重命名"
- 输入新文件名，确认后：
  - ✅ 物理文件自动重命名
  - ✅ **所有引用该资源的文档自动更新链接**，不会出现引用失效
- 智能后缀处理：忘记输入后缀名会自动补齐，修改后缀名会弹出确认
- 文件名合法性校验：自动拒绝包含非法字符（`\ / : * ? " < > |`）的名称

### 📄 查看引用文档

想知道某个资源被哪些文档使用了？

- 点击资源对应的 **"打开"** 按钮
- 自动在后台打开 **所有引用了该资源的文档**，并定位到引用位置
- 一键跳转，快速追溯资源的使用上下文

### 🗑️ 删除资源

删除不再需要的资源：

- 点击"删除"后，不仅物理文件被移除
- 文档中所有引用该资源的内容块也会被自动清理
- 如果清理后内容块变为空白，该块会被自动删除，保持文档整洁

### 🧹 一键清理孤儿资源

`assets` 文件夹里那些没有被任何文档引用的"孤儿"文件，占用空间却毫无用处：

- 点击 **"清理"** 按钮，一键识别并清理所有未被引用的资源
- 操作前会显示：待清理数量、预计释放空间大小
- 需二次确认，防止误操作

### 🖱️ 图片右键菜单集成

无需打开资源管家面板，在文档中直接操作：

- 在文档中的图片上 **右键**，菜单中出现 **"资源管家"** 子菜单
- **编辑** — 直接打开图片编辑器，保存后自动更新文档中的图片
- **重命名** — 直接重命名该图片资源，引用自动更新

## 🚀 如何使用

### 安装

1. 在思源笔记中打开 **集市** → **插件**
2. 搜索 **"资源管家"**（或 "Assets Manager"）
3. 点击安装并启用

### 打开资源管家

安装并启用后，思源笔记顶栏会出现 📦 **资源管家图标**，点击即可打开管理面板。

## 📋 使用场景

| 场景 | 操作 |
|------|------|
| 笔记库用了很久，想看看 assets 里有多少"垃圾" | 打开资源管家 → 筛选"未引用 (孤儿资源)" → 查看数量 → 一键清理 |
| 截图文件名是自动生成的乱码，想改成有意义的名称 | 资源管家中找到文件 → 重命名 → 引用自动更新 |
| 截图需要添加步骤标注（①②③） | 资源管家中编辑图片 → 使用序号标注功能 → 保存后文档自动更新 |
| 文档中的图片需要裁剪或加水印 | 右键图片 → 资源管家 → 编辑 → 裁剪/加文字 → 保存 |
| 想知道某张图片被哪些文档用到了 | 资源管家中查看"引用数"列 → 点击"打开"跳转到所有引用位置 |
| assets 文件夹很大，想按大小排序找出占空间最多的文件 | 打开资源管家 → 按"大小"降序排序 → 或筛选"大文件 (>1MB)" |

---

## ⚠️ 注意事项

- **清理操作不可撤销** — "清理"和"删除"功能会直接移除物理文件，操作前请确认资源确实不再需要
- **桌面端体验最佳** — 在 Electron 桌面端可直接读取文件系统，速度更快；浏览器端通过网络请求获取文件信息，大量资源时可能稍慢
- **首次加载** — 如果资源文件数量很多（数千个），首次打开资源管家时扫描可能需要几秒钟，后续操作均在内存中完成
